# Solar Shop landing page

A responsive HTML/CSS/JavaScript landing page based on the supplied Solar Shop reference screenshot and brand direction.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, use a local development server (for example VS Code Live Server).

## Files
- `index.html` — page structure and copy
- `styles.css` — responsive styling and editable design tokens
- `script.js` — mobile navigation, current year, demo enquiry form
- `assets/solarshop-logo.webp` — exact supplied Solar Shop logo

## Before publishing
- The Trilect identity is represented as editable text because an official Trilect logo/mark was not supplied. Replace the text treatment with the official asset when provided; do not redraw or approximate the official mark.
- Connect the enquiry form to the client's CRM, email endpoint, or form service. It currently shows a local demo confirmation only.
- Replace any photography URLs with client-approved, licensed image assets for production. The current image links are remote Unsplash images and require an internet connection.
- Confirm product names, service claims, contact details, warranty statements, partner marks, and all copy with the client before launch.
- The site uses Google Fonts (DM Sans and Manrope) when online, with system fallbacks.

## Brand tokens
Edit the CSS variables at the top of `styles.css` to make global brand adjustments.
